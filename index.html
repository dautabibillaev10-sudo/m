💻 Среды разработки и программирование

Arduino IDE Чему учит: Официальная среда разработки для Arduino. Научишься писать, компилировать и загружать программы в микроконтроллеры Arduino. Базовый инструмент для робототехники. VS Code + PlatformIO 📚 Чему учит: Профессиональная среда разработки. Научишься работать с PlatformIO для Arduino, ESP32, STM32. Продвинутая отладка, автодополнение кода, управление библиотеками. Thonny IDE 📚 Чему учит: Простая среда для программирования на Python. Идеальна для Raspberry Pi Pico и MicroPython. Научишься основам Python для микроконтроллеров. PlatformIO 📚 Чему учит: Профессиональная платформа для встраиваемых систем. Научишься работать с 500+ платами, управлять зависимостями, использовать Unit Testing. Python.org 📚 Чему учит: Официальный сайт Python. Научишься основам языка Python — от переменных до ООП. Необходим для Raspberry Pi, компьютерного зрения, AI. W3Schools Python 📚 Чему учит: Интерактивные уроки Python онлайн. Научишься синтаксису, структурам данных, функциям, работе с файлами. Есть онлайн-редактор для практики. LearnCpp.com 📚 Чему учит: Полный бесплатный курс C++. Научишься от основ (переменные, циклы) до продвинутых тем (шаблоны, умные указатели). Основа для Arduino программирования. GitHub 📚 Чему учит: Система контроля версий Git. Научишься сохранять код, работать с репозиториями, сотрудничать в проектах. Must-have для любого программиста.

🤖 Симуляторы и эмуляторы

Tinkercad Circuits 📚 Чему учит: Бесплатный онлайн-симулятор Arduino. Научишься собирать схемы без пайки, программировать Arduino блоками или кодом, тестировать проекты безопасно. Wokwi 📚 Чему учит: Продвинутый симулятор ESP32, Arduino, Raspberry Pi Pico. Научишься работать с WiFi, Bluetooth, датчиками. Есть отладчик и поддержка MicroPython. Falstad Circuit Simulator 📚 Чему учит: Визуальный симулятор электронных схем. Научишься понимать ток, напряжение, работу компонентов в реальном времени. Отлично для изучения основ электроники. EveryCircuit 📚 Чему учит: Интерактивный симулятор схем. Научишься проектировать и тестировать электронные схемы. Красивая визуализация тока и напряжения. CoppeliaSim (V-REP) 📚 Чему учит: Профессиональный симулятор роботов. Научишься моделировать роботов, программировать их поведение, тестировать алгоритмы без реального железа. Gazebo 📚 Чему учит: 3D симулятор для ROS. Научишься создавать виртуальных роботов, симулировать физику, тестировать навигацию и компьютерное зрение.

🔧 Проектирование и CAD

Fusion 360 📚 Чему учит: Профессиональный CAD/CAM/CAE. Научишься 3D моделированию деталей для роботов, созданию сборок, генерации G-code для ЧПУ. Бесплатно для студентов. FreeCAD 📚 Чему учит: Открытый параметрический 3D CAD. Научишься создавать детали, работать с эскизами, делать чертежи. Полностью бесплатная альтернатива Fusion 360. KiCad 📚 Чему учит: Проектирование печатных плат (PCB). Научишься создавать схемы, разводить платы, генерировать Gerber файлы для производства. Профессиональный инструмент. Fritzing 📚 Чему учит: Создание схем и PCB для начинающих. Научишься рисовать понятные схемы Arduino проектов, создавать простые платы. Отлично для документации проектов. Onshape 📚 Чему учит: Облачный CAD. Научишься 3D моделированию в браузере, совместной работе над проектами. Бесплатно для открытых проектов. Blender 📚 Чему учит: 3D моделирование и анимация. Научишься создавать сложные 3D модели, визуализировать проекты, делать рендеры. Бесплатный и мощный инструмент.

🤖 Робототехника и ROS

ROS / ROS2 📚 Чему учит: Robot Operating System. Научишься создавать сложные робототехнические системы, работать с нодами, темами, сервисами. Стандарт в робототехнике. OpenCV 📚 Чему учит: Библиотека компьютерного зрения. Научишься распознавать объекты, лица, цвета, отслеживать движение. Необходима для умных роботов. MATLAB Simulink 📚 Чему учит: Моделирование и симуляция динамических систем. Научишься создавать модели роботов, проектировать системы управления, анализировать поведение. Arduino Robot Library 📚 Чему учит: Готовые библиотеки для робототехники. Научишься использовать готовые решения для моторов, датчиков, дисплеев. Ускоряет разработку.

📖 Образовательные платформы

Coursera 📚 Чему учит: Курсы от ведущих университетов. Научишься робототехнике, машинному обучению, алгоритмам от профессоров Stanford, MIT. Сертификаты. edX 📚 Чему учит: Курсы от Harvard, MIT, Berkeley. Научишься компьютерным наукам, инженерии, программированию. Многие курсы бесплатны. Udemy 📚 Чему учит: Практические курсы по Arduino, Raspberry Pi, робототехнике. Научишься создавать реальные проекты от начинающих до продвинутых. GreatScott! Lab 📚 Чему учит: YouTube канал по электронике. Научишься проектировать схемы, паять, работать с инструментами. Много практических проектов. Andreas Spiess 📚 Чему учит: YouTube канал "The Guy with the Swiss Accent". Научишься работать с ESP32, датчиками, IoT. Глубокие технические обзоры. Random Nerd Tutorials 📚 Чему учит: Отличные уроки по ESP32 и ESP8266. Научишься создавать IoT устройства, работать с WiFi, Bluetooth, датчиками. Пошаговые руководства. MyRobot.ru 📚 Чему учит: Робот шаг за шагом (русский язык). Научишься создавать роботов с нуля — от простых до сложных. Много схем и кода. Instructables 📚 Чему учит: Тысячи DIY проектов. Научишься создавать электронные устройства, роботов, умный дом. Пошаговые инструкции с фото.

🔍 Документация и справочники

Arduino Reference 📚 Чему учит: Полная документация Arduino. Научишься всем функциям языка Arduino, работе с пинами, коммуникации. Официальный справочник. ESP32 Documentation 📚 Чему учит: Официальная документация Espressif. Научишься программировать ESP32 на C++, MicroPython, работать с WiFi, Bluetooth, периферией. Raspberry Pi Docs 📚 Чему учит: Документация Raspberry Pi. Научишься работать с GPIO, камерой, дисплеями, устанавливать ОС. Полное руководство. Datasheet Archive 📚 Чему учит: База данных даташитов. Научишься читать техническую документацию компонентов, понимать характеристики, правильно подключать.
